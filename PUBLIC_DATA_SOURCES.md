# Public respiratory-data sources

The respiratory-reserve evidence layer uses no patient database, public omics
cohort, or external model-training dataset. It uses figure-level oxygen
consumption measurements from the four primary studies below. All extracted
values and uncertainty records distributed by this project are publicly
downloadable under `inputs/audit_runs/`; original article images are not
redistributed.
