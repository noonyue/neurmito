The code used for the NeurMito-DT computational analyses is prepared as a
method-only repository containing model and analysis source code, cited source
records, locked audit inputs, tests, and environment specifications. Generated figures, tables,
source-data workbooks, manuscript text, and submission files are intentionally
excluded. Literature-derived values are documented as source-local relative
constraints. No new wet-lab, imaging, animal, intervention, patient-level,
clinical-efficacy, or external biological-validation data are included.

Release status: the local candidate has passed technical reviewer-access tests,
but reviewer distribution still requires author approval. Public release also
requires approved software creators, copyright ownership, a license, an
immutable GitHub commit/tag/Release and a verified archival DOI. No repository
URL or DOI may be cited as an active release until those steps are complete.
