# Repository Scope

## Included

- Model implementations and analysis code.
- Figure-generation and audit scripts as source code.
- Literature citations, derived source-audit records and parameter/input declarations.
- The 24 locked audit inputs required by the verified asset rebuild.
- Tests, environment specifications, and technical execution notes.

## Excluded

- Author information, submission metadata, and manuscript text.
- Generated figures, tables, source-data workbooks, manifests, and other result artifacts.
- Six literature-derived article images whose redistribution permission was not established for every image.
- Missing historical training histories, complete original trajectories and solver checkpoints.
- Manuscript-generation scripts outside the verified asset workflow.

## Evidence boundary

This package supports computational methods and source auditing only. It must
not be used to imply experimental validation or clinical performance.
Generated outputs are intentionally local and excluded from version control.
